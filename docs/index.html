Optional Google Drive connection

Your library, on your next device.

Start on one device and pick up your library on another. Connect Google Drive to sync saved generations, references, folders, and tags across macOS, Windows, iOS, and Android. Prefer to keep work local? The connection is entirely optional.

01

What Drive enables

Clawnsole creates an app-owned Drive folder so you can reopen generations, references, folders, and tags on another device and continue the same project workflow.

02

What Clawnsole stores

The folder can contain prompts, generation settings and history, saved-reference metadata, retained inputs, generated media, project folders, tags, and non-secret preferences.

03

What access is limited to

Clawnsole requests the narrow drive.file permission. It can access files it creates or files you explicitly make available to it, not the rest of your Google Drive.

Provider keys sync only inside a passphrase-encrypted vault. Google OAuth tokens are never stored in Drive. Drive content is sent to a generation provider only when you deliberately select that content as an input. You can disconnect Drive or delete Clawnsole's Drive data at any time.
