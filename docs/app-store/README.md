# App Store assets

These screenshots were captured from Clawnsole 0.21.0 using clean simulators
with App Review provider access but no displayed key, personal generation
history, prompt, or private media.

- `iphone/`: 1284 x 2778 pixels (iPhone 6.5-inch display, iPhone 14 Plus
  simulator)
  - `01-create.png`: LTX text-to-video creation
  - `02-providers.png`: the provider desk with connected providers
  - `03-library.png`: clean, device-local library
- `ipad/`: 2048 x 2732 pixels (iPad 12.9-inch or 13-inch display, iPad Pro
  12.9-inch simulator)
  - `01-create.png`: the full LTX creation console — knob slider, hardware
    switch, console keys, and estimated-charge panel in one view
  - `02-providers-dark.png`: provider keys and cost desk in dark mode
  - `03-library-dark.png`: clean, device-local library in dark mode

Keep store screenshots free of provider credentials and user data. Replace the
set when a release materially changes the generation workflow or product
branding.
